# ⚡ دوره صفر تا صد Zustand و TanStack Query — مدیریت جامع State کلاینت و سرور در React

> 🤖 **تولید شده توسط هوش مصنوعی:** این دوره به‌طور کامل توسط مدل **GLM-5.3-Flash** تولید و تدوین شده است.
> **نسخه دوره:** مدرن — با آخرین نسخه React 19، Zustand v5 و TanStack Query v5
> **پیش‌نیاز:** آشنایی با React و هوک‌های پایه نظیر `useState` و `useEffect`

---

## 🎯 چرا Zustand و TanStack Query؟

در اپلیکیشن‌های مدرن فرانت‌اند، جداسازی **Client State** (وضعیت رابط کاربری مانند تم، مدال‌ها، فیلترها و سبد خرید) از **Server State** (داده‌های واکشی‌شده از API با نیاز به کش، بازنشانی، مدیریت لودینگ و خطا) کلید داشتن کدی تمیز، پایدار و پرسرعت است. این دوره کامل‌ترین مرجع فارسی برای تسلط بر این دو غول مدرن ری‌اکت است.

---

## 🗺️ نقشه سرفصل‌های دوره

### بخش اول · Zustand — مدیریت State سمت کلاینت
| فصل | موضوع | مباحث کلیدی |
|---|---|---|
| فصل ۱ | مدیریت State — چرا، کِی و با چه ابزاری؟ | انواع State در وب، مقایسه Context و Redux با Zustand، فلسفه سادگی |
| فصل ۲ | Zustand از صفر — نصب و اولین استور | ایجاد اولین Store با تابع `create`، اکشن‌ها، خواندن و به‌روزرسانی در کامپوننت |
| فصل ۳ | عمق Zustand — set، get و کار با استور از هر جا | عملکرد توابع `set` و `get`، اکشن‌های ناهمگام (Async)، دسترسی خارج از کامپوننت‌های ری‌اکت |
| فصل ۴ | Selectors و بهینه‌سازی رندر | انتخاب هدفمند بخش‌هایی از استور، جلوگیری از رندرهای اضافه و مقایسه سطحی (`shallow`) |
| فصل ۵ | Middlewareها — persist، devtools و immer | ذخیره‌سازی خودکار در LocalStorage با `persist`، دیباگ با Redux DevTools و استیت‌های تودرتو با Immer |
| فصل ۶ | الگوهای حرفه‌ای Zustand — TypeScript و اسلایس‌ها | تایپ‌اسکریپت استاندارد برای استور، خرد کردن استور با Slice Pattern، و استفاده از `subscribeWithSelector` |
| فصل ۷ | پروژهٔ عملی ۱ — سبد خرید کامل با Zustand | پیاده‌سازی گام‌به‌گام سبد خرید، محاسبه قیمت نهایی، اعمال کد تخفیف، افزایش/کاهش و ماندگاری دیتا |

### بخش دوم · TanStack Query — مدیریت Server State
| فصل | موضوع | مباحث کلیدی |
|---|---|---|
| فصل ۸ | TanStack Query و دنیای Server State | تفاوت بنیادی دیتای سرور، معماری کش، راه‌اندازی `QueryClient` و `QueryClientProvider` |
| فصل ۹ | useQuery — خواندن داده از سرور | ساختار `queryKey` و `queryFn`، وضعیت‌های `isPending` و `isError`، مفهوم `staleTime` و `gcTime` |
| فصل ۱۰ | useMutation — تغییر داده و به‌روزرسانی کش | ارسال POST/PUT/DELETE با هوک `useMutation`، باطل‌سازی کش (`invalidateQueries`) و Optimistic Updates |
| فصل ۱۱ | Query Keys و مدیریت کش | معماری کلیدهای تمیز با Query Key Factory، فیلترهای کش و پیش‌واکشی داده‌ها (`prefetchQuery`) |
| فصل ۱۲ | امکانات پیشرفته — صفحه‌بندی، Infinite و Suspense | صفحه‌بندی بدون پرش (Pagination)، اسکرول بی‌نهایت با `useInfiniteQuery`، و ابزار DevTools |
